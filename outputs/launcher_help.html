ChaoxingAI / 首次使用

三步连接你的 AI

你无需安装 Python，也无需编辑配置文件。密钥只需配置一次；以后双击启动器即可。

1. 在 DeepSeek 官方平台创建密钥

  1. 打开 DeepSeek API 密钥页面，在官方页面完成注册或登录。
  2. 找到 API keys / API 密钥，创建一个新密钥，名称可以填“ChaoxingAI”。
  3. 复制完整密钥。不要发给他人，也不要贴到脚本代码、反馈截图或聊天中。

DeepSeek 的聊天网页与 API 是不同的使用入口。API 可能收费；请在官方平台检查余额与额度。本工具的“获取密钥”按钮不会替你注册、充值或接受协议。

2. 粘贴，测试并保存

回到启动器，把密钥粘贴到“API 密钥”输入框，点击“测试并保存，启动服务”。测试会发送一道很短的示例题，可能产生少量 API 费用。等到状态显示“服务运行中 / 已就绪”即可。

默认模型为 deepseek-flash。多数情况下无需改动；如账号使用其他模型，在“高级设置”中填写官方提供的模型名称。

3. 安装脚本，打开学习通

点击启动器中的“安装 / 更新浏览器脚本”，从 脚本猫项目页安装普通脚本。停用其他同类脚本，刷新学习通课程页。

保持启动器运行，可以最小化。关闭启动器会停止 AI 服务。首次使用请观察一个章节的完整流程，AI 建议不保证正确。

常见提示

  • 密钥无效：重新复制完整密钥，检查是否被撤销。
  • 余额或额度不足：到 DeepSeek 官方平台检查，工具不会自动充值。
  • 模型不可用：在高级设置中使用账号当前支持的模型。
  • 已有服务正在运行：如果以前开过 server.py，先在原窗口按 Ctrl+C 停止，再在启动器中启动服务。
  • 重复双击：启动器会提示使用已有窗口，不会启动两个服务。

已有旧配置怎么办？

使用启动器的“导入原 .env”，选择原项目 outputs 目录中的 .env；测试通过后会另行加密保存，原文件不会被修改。新启动器使用独立缓存，第一次运行不会搬运旧缓存。

配置和缓存位于 Windows 当前用户的 %LOCALAPPDATA%\ChaoxingAI。密钥由 Windows 当前账号加密；复制配置文件到另一台电脑通常无法解密，需要重新输入密钥。
