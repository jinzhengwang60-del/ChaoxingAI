# 使用与排错

浏览器脚本 4.0.11-ai；启动器 1.0.1。安装入口见仓库根目录 README.md。首次使用自动提交时，请观察页面结果。

## 推荐：Windows 图形启动器

[下载 Windows 启动器 v1.0.1](https://github.com/jinzhengwang60-del/ChaoxingAI/releases/download/launcher-v1.0.1/ChaoxingAI-Windows-v1.0.1.zip)，也可查看[版本说明和校验文件](https://github.com/jinzhengwang60-del/ChaoxingAI/releases/tag/launcher-v1.0.1)。

解压 `ChaoxingAI-Windows-v1.0.1.zip`，双击 `ChaoxingAI-Launcher.exe`。首次使用按界面提示获取 API 密钥，粘贴后点击“测试并保存，启动服务”。密钥使用当前 Windows 账号加密保存；以后双击自动启动。无需安装 Python，无需编辑 .env。详细教程可在启动器中打开。

升级时先退出旧启动器，再打开新版；同一 Windows 账号会继续读取已保存配置。浏览器脚本也需更新到 4.0.11-ai，可从脚本猫更新或导入发布包里的 `ChaoxingAI.user.js`，保存后刷新课程页。

若以前正在运行 server.py，请先在原服务窗口按 Ctrl+C 停止，避免占用同一端口。已有 .env 可通过“导入原 .env”读取，原文件和旧缓存不改动。保持启动器运行，可以最小化；退出会停止本地服务。

启动器配置与缓存位于 `%LOCALAPPDATA%\ChaoxingAI`。连接测试会产生一次短的真实 API 请求，可能有少量费用。没有密钥或额度不足时会在界面给出提示，不需要查看终端日志。

4.0.10-ai 移除了旧题库配置面板（公众号提示、Token 输入框、保存按钮及开发中提示）和对应界面初始化逻辑。AI 密钥仍在本地 .env 配置。替换浏览器脚本全文并刷新即可。

## 从源码日常启动

从项目根目录运行 `python outputs/server.py`，保持终端打开。Ctrl+C 停止服务，可能显示 KeyboardInterrupt；这表示服务已中断。服务关闭不会阻止脚本面板加载，但无法取得新的 AI 建议。

普通脚本安装到脚本猫；不要选择后台脚本。每次更新时覆盖已有脚本全文，保存后刷新课程页面，避免同时启用多个版本。

## 页面状态

- 左下角状态框表示脚本已加载；“运行中断”后文字可用于排错。
- 有建议无选择时，查看建议区最后一行的匹配或暂停原因。
- 全部题目核对后倒计时 5 秒提交；可使用题目页顶部“暂停自动选择与提交”。
- 有未知题型、未成功选择、人工修改或暂停，不自动提交。
- 本测试已尝试提交时不重复提交。请先核实网站状态，结果不明不要重复操作。
- 30 秒未确认进入结果页会显示待确认提示；网站可能需要手动确认弹窗。

## DeepSeek 超时或连接失败

1. 本地服务对超时、临时断线、HTTP 429 和临时服务错误最多尝试 3 次，间隔逐渐增加。分析期间保持启动器运行，等待题目提示更新。
2. 仍失败时显示具体原因与尝试次数，当前题目不会视为已核对，也不会提交。恢复网络后点击题目页顶部“重试失败题目”，成功题目的建议会保留。
3. “密钥无效”“余额或额度不足”“模型不存在”需在启动器或官方平台修正，不会自动重复请求。证书验证失败时检查系统时间与网络证书设置。
4. “无法连接本地服务”表示浏览器没有连上本机启动器；先确认启动器显示服务运行中。健康检查 `/health` 的 ok 仅代表本机服务可访问，不代表 DeepSeek 一直可用。
5. 已暂停或手动改过答案时，重试仍遵守原有保护。不要为了恢复分析反复提交或跳章。

重试可能产生额外 API 费用。上游繁忙、限流和账号错误含义参见 [DeepSeek 官方错误说明](https://api-docs.deepseek.com/quick_start/error_codes/)。

## 配置与隐私

.env 从服务所在目录读取，不依赖终端当前目录。修改配置后重启服务。不要公开 .env、密钥、缓存和带个人账号信息的截图；提问题时可以附脱敏的状态提示。

服务使用 DeepSeek 的兼容接口：https://api-docs.deepseek.com/api/create-chat-completion/

原脚本及许可说明位于 source/auto.js 与 NOTICE.md。源代码中的原有外部地址和视频逻辑保留，部署前可自行审阅。
