## 浏览器脚本 4.1.0-ai：课程内面板更新

本次更新学习通页面里的脚本面板。Windows 启动器和本地服务继续使用 1.0.1，无需重配 API 密钥。

- 顶部显示当前任务状态、本页进度和本地服务状态。
- 本页任务逐项显示进行中、已完成、等待或待处理；右侧课程目录与原有章节入口保留。
- 设置集中为视频倍速、复习模式和 AI 辅助测验；输入倍速后点击“应用”。
- 运行记录默认显示最新 3 条，可展开查看最多 50 条，重要异常在顶部提示。
- 移除已不参与 AI 核对的“章节测试正确率”输入和无实际切换作用的旧保存/提交按钮。
- 题目页的暂停、重试和建议区统一样式，继续沿用自动选择、全部核对后 5 秒提交、人工操作保护和结果页确认。

安装时使用 `ChaoxingAI-4.1.0.user.js` 全文替换旧版普通脚本，停用重复版本，再刷新课程页面。旧 Windows 1.0.1 发布包内附带 4.0.11-ai，获取本次面板需单独更新浏览器脚本。

“检测连接”只检查本机服务，不请求收费 AI，也不保证 DeepSeek 上游可用。任务进度只统计当前页面，不代表整门课程。AI 建议仍可能错误。

本次用模拟课程验证面板状态、设置、日志及窄屏排版，并运行原有浏览器回归测试。模拟验证不等于已验证所有真实课程、浏览器和收费 API。
