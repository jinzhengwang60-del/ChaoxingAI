## Windows 启动器 v1.0.0

本版本新增图形启动器，让 Windows 用户无需安装 Python、编辑 .env 或输入启动命令。浏览器脚本继续使用 **4.0.10-ai**，自动选择、自动提交和章节推进逻辑没有修改。

### 下载与开始使用

下载下方 **ChaoxingAI-Windows-v1.0.0.zip**，完整解压，双击 **ChaoxingAI-Launcher.exe**。

1. 首次使用点击“获取 API 密钥”，在 DeepSeek 官方平台创建自己的密钥。
2. 粘贴密钥并点击“测试并保存，启动服务”。
3. 显示“已就绪”后，点击“安装 / 更新浏览器脚本”，刷新学习通页面。
4. 以后双击启动器即可自动启动服务；可以最小化，退出会停止服务。

如果以前运行着 `server.py`，先在原终端按 Ctrl+C 停止，再使用新启动器。旧 .env 可通过“导入原 .env”读取，原文件不会被修改。

### 新增功能

- 带中文说明的首次配置向导、获取密钥入口和随程序附带的教程。
- 真正调用示例题的连接测试，不以“填了密钥”冒充连接成功。
- Windows 当前账号加密保存密钥，后续自动读取配置。
- 启动、停止、重复启动与端口占用处理。
- 密钥无效、余额或额度不足、模型不可用、请求频繁和连接失败的提示。
- 模型高级设置，默认 `deepseek-flash`。

### 数据与使用说明

用户仍需自己的 DeepSeek API 密钥；API 可能收费，连接测试会产生一次短请求。密钥与缓存保存在用户电脑，发布包不包含开发者密钥、.env、缓存或测试配置。

配置目录为 `%LOCALAPPDATA%\ChaoxingAI`。密钥使用当前 Windows 账号加密，迁移到其他电脑后通常需要重新输入。

AI 建议不保证正确。请在课程允许的范围内使用，并在首次使用时观察完整章节流程。
