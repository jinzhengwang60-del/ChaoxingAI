## Windows 启动器 v1.0.1：连接超时恢复

本次同时更新本地服务与浏览器脚本。升级后请使用 **启动器 1.0.1 + 浏览器脚本 4.0.11-ai**。

### 更新内容

- DeepSeek 响应超时、临时断线、HTTP 429 或临时服务错误时，先等待再重试，每次分析最多尝试 3 次。
- 保留递增等待间隔，遵守上游 Retry-After 提示；整体重试预算约 225 秒。浏览器等待时间相应延长。
- 限制响应正文读取时间，避免空白保活内容让请求持续等待。
- 密钥无效、余额不足、模型配置错误和证书验证失败直接提示，不自动反复请求。
- 题目页新增“重试失败题目”，恢复后只分析失败的题目，复用已有建议区。
- 重试过程中保持人工修改、暂停、答案核对和重复提交保护；未核对的题目会阻止提交。
- 网络恢复失败不会写入答案缓存，成功答案仍可复用缓存。

### 升级方式

1. 退出旧启动器，或在旧 server.py 窗口按 Ctrl+C 停止服务。
2. 下载并解压 **ChaoxingAI-Windows-v1.0.1.zip**，双击 **ChaoxingAI-Launcher.exe**。
3. 同一个 Windows 账号会继续读取原有加密配置，通常不需要重新填写密钥。
4. 将浏览器脚本更新到 **4.0.11-ai**。可从脚本猫更新，也可在脚本猫扩展中导入包内 **ChaoxingAI.user.js**。停用其他版本，刷新课程页面。

源码运行用户更新 outputs/server.py 和 outputs/auto-ai.js，重启服务并刷新课程页即可。

### 验证与使用说明

自动化测试模拟了超时后恢复、连续失败、限流、证书错误、无效密钥、错误缓存、失败题目重试与提交保护，不调用真实收费 API。用户遇到超时的实际原因仍需结合具体错误提示判断；本更新提高恢复能力，无法保证网络或上游服务始终可用。

程序为 Windows x64 构建，未进行发布者代码签名。用户仍需自己的 DeepSeek API 密钥；重试可能产生额外 API 费用。配置与缓存不随发布包分发。包内附带对应源码与 GPL-3.0-or-later 许可证。
