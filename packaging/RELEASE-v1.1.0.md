# 在学习通页面启动本地服务

配套版本：浏览器脚本 **4.2.0-ai**，Windows 启动器 **1.1.0**。

- 面板新增“启动并连接”。在浏览器提示中允许打开 ChaoxingAI 后，启动器读取已保存的加密配置并启动服务。
- 页面最多等待 60 秒，通过本地健康检查确认连接；支持取消等待。没有启动或未完成配置时显示后续步骤，不把唤起请求当作连接成功。
- 首次在启动器中点击“启用 / 修复页面启动”。仅为当前 Windows 账号注册关联，不需要管理员权限；可在同一窗口停用。请保留程序位置，移动后重新启用。
- 已打开的启动器接收启动通知；停止的服务可以重新启动，运行中的服务不会重复启动。
- 原有加密配置、任务进度、视频设置、AI 请求重试、选择核对及提交保护继续使用。启动服务和检测连接不进行收费 API 测试。

升级：退出旧启动器，完整解压新版，运行并启用页面启动；在脚本猫扩展中导入包内 `ChaoxingAI.user.js` 并刷新课程页。原有启动器配置无需重填。原来只运行 `server.py` 的用户，可通过“导入原 .env”迁移一次；原配置文件不会修改，首次测试可能产生少量 API 费用。

浏览器仍可能询问是否打开本地应用，用户需要在提示中允许。等待取消只停止页面检测；退出启动器才会停止其服务。此功能使用固定的 `chaoxingai://start` 链接，不接收密钥、文件路径、命令或查询参数。

原件 `source/auto.js` 保留。此版本不重新实现或修改测验答题和提交流程。
